# Investigación sobre la Vacunación del COVID-19 🦠💉

## Descripción del Proyecto

Este repositorio alberga un trabajo de investigación exhaustivo sobre la vacunación contra el COVID-19 en España, empleando diversas metodologías de programación en Python. El objetivo principal es analizar y extraer conocimientos profundos de datos relacionados con la pandemia y las campañas de vacunación, utilizando técnicas avanzadas de **Machine Learning (no supervisado)**, **Procesamiento del Lenguaje Natural (NLP)**, y **Deep Learning**. El proyecto busca identificar patrones, predecir tendencias y comprender el impacto de la vacunación desde múltiples perspectivas, con un enfoque particular en el contexto español. ✨

## Metodologías Implementadas

Este proyecto explora y aplica diversas metodologías computacionales:

-   **Machine Learning (ML) No Supervisado:** Se utilizan algoritmos no supervisados para descubrir patrones ocultos, agrupar datos o reducir dimensionalidad en los conjuntos de datos de vacunación. 💡
-   **Procesamiento del Lenguaje Natural (NLP):** Aplicación de NLP para analizar textos relacionados con la vacunación, posiblemente extrayendo información clave o analizando sentimiento. 💬
-   **Deep Learning (DL):** Implementación de redes neuronales profundas para el análisis de datos más complejos o series temporales. 🧠
